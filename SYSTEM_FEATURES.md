# 🏪 Point of Sale (POS) Management System

## 🚀 Getting Started

### **System Requirements**
- **Server**: PHP 7.4+ with Laravel requirements
- **Database**: MySQL 5.7+ or MariaDB
- **Web Server**: Apache or Nginx
- **Browser**: Modern web browser (Chrome, Firefox, Safari, Edge)

### **Default Login**
- **Username**: admin
- **Password**: admin123

### **Quick Setup**
1. Install dependencies with `composer install`
2. Configure database in `.env` file
3. Run migrations with `php artisan migrate`
4. Seed sample data with `php artisan db:seed`
5. Start server with `php artisan serve`
